# 层次聚类

## 一句话认识

逐步合并相近样本（凝聚式）或逐步拆分群体（分裂式），形成从细到粗的树状结构，适合观察多层次关系。

## 1. 凝聚式流程

1. 每个样本自成一簇；
2. 计算簇间距离；
3. 合并最近的两个簇；
4. 更新距离，直到只剩一簇；
5. 在树状图某一高度切割得到最终簇。

与 K-Means 不同，它不需在运行前固定簇数，但最终仍需依据切割规则选择簇数。

## 2. 距离与连接方法

样本距离可用欧氏、曼哈顿、Gower 等；选择取决于变量类型和“相似”的含义。

| 连接方法 | 簇间距离 | 特点 |
|---|---|---|
| Single | 最近样本距离 | 能识别链状结构，易产生 chaining |
| Complete | 最远样本距离 | 簇紧凑，对离群点敏感 |
| Average | 所有跨簇距离平均 | 折中、常较稳定 |
| Ward | 合并造成的簇内平方和增量 | 偏好紧凑簇，通常配平方欧氏距离 |

距离与连接方法共同定义结果，不能只写“使用层次聚类”。

## 3. 数据准备

- 连续变量通常需要缩放；
- 混合数值、二元和类别变量可考虑 Gower 距离；
- 高相关特征会重复影响距离；
- 异常点可能在树状图很高处才合并，应先判断其意义；
- 样本很大时，完整距离矩阵的存储和计算成本较高。

## 4. 如何切树

- 观察合并距离的明显跃升；
- 比较多个簇数下的轮廓系数等内部指标；
- 使用动态切树或稳定性方法；
- 结合每簇规模、解释性与决策用途；
- 不要以树状图“看起来像”作为唯一证据。

树状图的横向顺序可旋转，不能把相邻叶子顺序过度解释；重要的是合并高度和分支结构。

## 5. 建模流程

1. 定义对象、特征与相似性；
2. 选择并说明预处理和距离；
3. 比较 2–3 种有依据的连接方法；
4. 查看树状图和合并距离；
5. 对候选切割数计算内部指标与稳定性；
6. 给各簇做画像并用外部变量验证；
7. 报告方法/切割变化下哪些分支稳定。

## 6. 改进阶梯

- 从单一距离升级为适合混合数据的距离；
- 对指标相关性做筛选或降维；
- 用 Bootstrap 评估分支重现频率；
- 使用共识矩阵汇总多个距离/连接方案；
- 对超大样本先抽样或微聚类，再解释代表性；
- 与 K-Means 比较：若 Ward 结果稳定，可用其中心初始化 K-Means。

## 7. 检验

- Cophenetic 相关可辅助判断树结构保存原距离的程度；
- 改变缩放、距离、连接方法后的簇一致性；
- 重抽样后的分支稳定性；
- 极小簇是否由异常点驱动；
- 外部变量差异和实际可用性。

内部指标高只说明在选定距离下分离较好，不证明类别有客观实体性。

## 8. 常见错误

- 忽略不同连接方法含义；
- Ward 法与不合适的任意距离组合；
- 仅凭一张树状图决定簇数；
- 样本太多仍绘制无法阅读的全量标签；
- 对横向叶子顺序进行因果或时间解释；
- 不检查单个异常点是否改变整棵树。

## 9. 论文表达与 AI 协作

应展示变量与距离定义、连接方法对比、可读树状图、切割依据、簇画像、稳定性和外部验证。让 AI 实现时明确距离度量与变量类型，要求返回合并表、候选切割结果及不同方法的一致性矩阵，而非只生成树状图。
