# 04 分类聚类类模型

## 先分清：有无标签

- **聚类**：没有预先给定的正确类别，算法按相似性寻找群体结构。结果不是天然“真相”，必须解释和验证。
- **分类**：已有标签，学习从特征到类别的映射，并在未见样本上评价。
- **PCA**：本身既不是聚类也不是分类，而是降维与解释工具，可为二者服务。

## 五个主题如何选

| 主题 | 适合结构 | 主要局限 |
|---|---|---|
| [K-Means](01_K-Means聚类.md) | 近似球形、尺度相近、连续变量 | 需给定 $K$，怕异常值 |
| [层次聚类](02_层次聚类.md) | 样本中小、希望看嵌套关系 | 距离/连接方法敏感 |
| [DBSCAN](03_DBSCAN聚类.md) | 不规则形状、含噪声 | 密度差异大时难设参数 |
| [PCA 降维解释](04_PCA降维解释.md) | 高相关连续特征 | 线性、对尺度和异常敏感 |
| [随机森林分类](05_随机森林分类.md) | 有标签、非线性表格数据 | 不能外推，概率需校准 |

## 聚类题的最低要求

1. 解释样本和特征为何适合按距离比较；
2. 说明缩放、异常和类别变量处理；
3. 不能只用一项内部指标决定簇数；
4. 报告不同参数、抽样和随机种子下的稳定性；
5. 为每簇给出画像、规模和现实意义；
6. 用外部变量验证，但不要把用于聚类的变量又当独立验证证据。

## 分类题的最低要求

训练测试隔离、类别不平衡处理、混淆矩阵、适合任务的指标、阈值选择、概率校准、特征解释和分群误差。
