# 02 评价决策类模型

评价模型把多个指标合成为分数、排名或等级。真正困难的不是套公式，而是回答三个问题：**评价对象是否可比？指标是否代表目标？权重和聚合规则是否有依据？**

## 推荐工作流

1. 定义评价目标、对象、时间和使用者。
2. 建立可解释、可测量、尽量不重复的指标体系。
3. 处理方向、量纲、缺失、极端值和高度相关指标。
4. 选择权重：主观、客观或组合，并说明它代表什么。
5. 选择聚合/排序方法，得到分数、贴近度或等级。
6. 做权重、标准化、样本变化下的排序稳定性分析。
7. 解释得分由哪些指标驱动，避免只给名次。

## 五个主题的分工

| 主题 | 主要用途 | 关键前提/局限 |
|---|---|---|
| [指标体系构建](01_指标体系构建.md) | 定义“评价什么” | 决定上限，不能由算法代替 |
| [熵权法 + TOPSIS](02_熵权法_TOPSIS.md) | 用离散度赋权并按理想解排序 | 熵权是差异权，不等于价值重要性 |
| [AHP + 模糊综合评价](03_AHP_模糊综合评价.md) | 融合专家偏好和模糊等级 | 要检查一致性和专家稳健性 |
| [PCA 综合评价](04_PCA_综合评价.md) | 从相关指标提取少数公共维度 | 线性、依赖样本，主成分未必有现实含义 |
| [灰色关联分析](05_灰色关联分析.md) | 比较曲线与参考序列的接近程度 | 表示相似关联，不证明因果 |

## 一定要报告的内容

- 指标定义、方向、单位、来源和时间范围；
- 预处理与权重公式；
- 分项得分与总分，而不只是排名；
- 改变权重、标准化方式或删去单项后的排名变化；
- “高分意味着什么”以及“不意味着什么”。
