# 03 预测类模型

预测问题不是“找拟合度最高的曲线”，而是利用预测时点之前可获得的信息，估计未来未知量及其不确定性。

## 预测建模主线

1. 明确预测对象、时间粒度、预测提前量和使用场景。
2. 定义预测时真正可获得的特征，防止未来信息泄漏。
3. 按时间或独立样本划分训练、验证、测试集。
4. 先建立简单基线，再训练候选模型。
5. 在同一测试范围、同一指标上公平比较。
6. 报告区间、残差、分群误差和极端情景，而不只报平均误差。
7. 根据决策成本选择模型；最小 RMSE 不一定是最有用的模型。

## 五个主题如何选

| 主题 | 优势 | 主要风险 |
|---|---|---|
| [回归预测](01_回归预测.md) | 解释变量影响清晰，可做情景预测 | 关系形式、共线性、外推 |
| [时间序列预测](02_时间序列预测.md) | 利用趋势、季节和自相关 | 时间泄漏、结构突变 |
| [机器学习预测](03_机器学习预测.md) | 捕捉复杂非线性和交互 | 小样本过拟合、解释不足 |
| [灰色预测](04_灰色预测.md) | 小样本、短期、平滑序列 | 指数趋势假设强，不适合波动大序列 |
| [预测模型对比](05_预测模型对比.md) | 公平选择或组合模型 | 划分/指标不一致造成伪提升 |

## 预测题最低要求

- 与朴素预测或均值/趋势基线比较；
- 训练与测试严格分开；
- 给出 MAE/RMSE 等误差的原单位解释；
- 对时间序列使用滚动或扩展窗口验证；
- 给出预测区间或情景范围；
- 说明模型在多远的未来、哪些条件下可用。
