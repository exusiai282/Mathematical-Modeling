# 05 传播与网络类模型

传播与网络问题关注个体之间的连接如何改变总体结果。关键不在画一张网络图，而在于明确：**节点和边代表什么、状态如何变化、参数从哪里来、干预如何进入机制。**

## 四个主题如何选

| 主题 | 核心问题 | 典型输出 |
|---|---|---|
| [SIR / SEIR](01_SIR_SEIR模型.md) | 人群在易感、暴露、感染、移出状态间转移 | 峰值、峰值时间、最终规模、干预效果 |
| [图论网络分析](02_图论网络分析.md) | 网络结构、关键节点、社群和脆弱性 | 中心性、社区、连通性、鲁棒性 |
| [信息传播](03_信息传播模型.md) | 消息、行为或创新如何经邻居激活扩散 | 传播范围、速度、种子节点、阈值 |
| [风险扩散](04_风险扩散模型.md) | 故障、金融或供应链风险如何级联 | 失效概率、级联规模、关键暴露、缓解方案 |

## 通用建模流程

1. 定义节点、边、方向、权重和时间尺度；
2. 定义每个节点的状态及状态转移规则；
3. 区分网络结构参数与传播动力学参数；
4. 用数据估计或校准参数，报告不可识别与不确定性；
5. 从小网络、极端参数和守恒关系验证实现；
6. 用历史传播/级联数据做样本外验证；
7. 比较基线、干预与多情景，输出分布而不只单次模拟。

## 三个常见误区

- 中心性高不等于一定最适合干预；要放进具体传播模型验证。
- 曲线拟合好不等于参数唯一；多组参数可能产生相似曲线。
- 传播模拟含随机性；必须重复运行并报告均值、分位数和极端结果。
