# 01 优化类模型

优化问题的本质是：**选择可控制的决策变量，在满足约束的前提下，使一个或多个目标尽可能好。**

## 建模主线

1. 明确“谁能决定什么”，将其定义为决策变量。
2. 把“最好”翻译成可计算的目标函数。
3. 把预算、容量、时间、逻辑和政策要求翻译成约束。
4. 先求一个确定性基础模型，再处理非线性、整数、多目标和不确定性。
5. 验证解的可行性与稳定性，而不只是报告“最优”。

## 五类问题如何区分

| 问题 | 决策核心 | 典型目标 | 常见约束 |
|---|---|---|---|
| [资源分配](01_资源分配模型.md) | 各对象分多少 | 收益最大、成本最小 | 总量、上下限、配额、公平 |
| [路径规划](02_路径规划模型.md) | 走哪些边、访问顺序 | 距离/时间/风险最小 | 连通、访问、容量、时间窗 |
| [选址](03_选址模型.md) | 设施开在哪里、服务谁 | 建设与服务成本最小 | 数量、容量、覆盖、距离 |
| [调度](04_调度模型.md) | 谁在何时做什么 | 完工期、延误、切换成本最小 | 资源冲突、先后、班次 |
| [多目标优化](05_多目标优化模型.md) | 在冲突目标间取舍 | 成本、效果、公平、风险 | 原问题约束与偏好信息 |

## 先判断模型类型

- 变量和关系都线性：线性规划（LP）。
- 存在“选/不选”、数量必须为整数：整数或混合整数规划（IP/MILP）。
- 含乘积、平方、比例等：非线性规划（NLP），先判断能否线性化。
- 决策分多个阶段且状态随时间变化：动态规划、模型预测控制或多阶段优化。
- 参数不确定：情景、随机优化或稳健优化。

求解器只是执行数学模型。论文的主要篇幅应解释变量、目标、约束为何符合现实，以及方案对参数变化是否稳定。

## 优化题必做检查

- 是否存在“无界获利”或变量缺少上下界？
- 是否遗漏资源守恒、唯一分配或互斥逻辑？
- 大常数 $M$ 是否有合理上界，而非随手写极大数？
- 不可行时，是数据冲突、约束过严，还是索引写错？
- 是否与简单规则比较，如平均分配、最近分配、先到先服务？
- 参数变化后，推荐方案是否频繁跳变？若是，需讨论决策风险。
