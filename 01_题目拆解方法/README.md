# 01 题目拆解方法

拆题的目标不是立刻选算法，而是把题目翻译成一组可验证的数学任务：研究对象是什么、已知什么、需要决定什么、受哪些条件限制、最终要提交什么结果。

## 专题导航

- [通用拆题流程](01_通用拆题流程.md)：从首次通读到形成建模任务表。
- [按题型拆解](02_按题型拆解.md)：优化、评价、预测、分类聚类、传播网络和社会政策题的识别重点。
- [常见误判](03_常见误判.md)：检查题意、模型方向、子问题关系和最终输出。

## 拆题完成标志

开始建模前，队伍应能用一页纸回答以下问题：

1. 每个子问题要求回答什么，输出形式是什么？
2. 哪些量是已知数据、待估参数和决策变量？
3. 子问题之间如何传递数据或结论？
4. 目标函数、评价标准或预测对象是什么？
5. 哪些限制来自题目原文，哪些来自必要假设？
6. 如何判断结果正确、可行且有现实意义？
