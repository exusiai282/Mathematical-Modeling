## 推荐学习路径

1. 从[题目拆解方法](01_题目拆解方法/README.md)学会识别输入、输出、目标和约束。
2. 阅读[模型选择与通用工作流](02_常见建模套路/00_模型选择与通用工作流.md)，再进入对应模型专题。
3. 用[建模技巧与模型改进](03_建模技巧与模型改进/README.md)补齐假设、检验和递进逻辑。
4. 对照[优秀论文拆解模板](05_优秀论文拆解/论文拆解模板.md)复盘论文，而不是只抄模型名称。
5. 写作阶段结合[英文论文写作](04_英文论文写作技巧/README.md)和[图表表达](06_图表与结果表达/README.md)。
6. 使用 AI 时先阅读[风险检查](07_AI辅助建模使用/05_AI使用风险.md)，所有公式、来源和结果都需人工验证。

## 仓库约定

- 目录按竞赛工作流编号，章节入口统一使用 `README.md`。
- Markdown 是主要阅读版本；`原始文档/` 与 `原始论文/` 保存二进制原件。
- 模型专题强调“问题识别 → 建模 → 求解 → 检验 → 改进 → 表达”，不以堆叠算法为目标。
- 提示词中的 `[ ]` 是待替换占位符，不应原样提交到论文或代码。
