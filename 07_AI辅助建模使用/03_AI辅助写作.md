# 03 AI 辅助写作

写作是 AI 最强的辅助领域，但也是最容易翻车的地方——AI 生成的文字看起来流畅，但可能言之无物、缺乏数学细节。**核心原则：AI 写草稿，你来注入数学内容；AI 做润色，你来把控逻辑。**

---

## ▍国赛部分（中文论文）

### 1. 摘要生成与修改提示词

**方法论：** 国赛摘要（Summary）是论文的门面，评委第一眼就看它。摘要必须包含：问题简述 → 建模思路 → 求解方法 → 主要结果 → 结论/建议。AI 可以帮你从正文各部分抽取关键句并组装成摘要，但它不知道"哪句话最重要"——你需要自己圈定关键信息喂给 AI。

**提示词模板：**
```
请根据以下论文各部分的关键信息，撰写一份国赛数学建模论文的摘要。要求：

【结构要求】
- 第1段（2-3句）：简述问题背景和核心挑战
- 第2段（3-4句）：针对问题一，用了什么模型、什么方法、得到什么结果
- 第3段（3-4句）：针对问题二，模型如何递进/改进，得到什么结果
- 第4段（3-4句）：针对问题三（如有），模型和方法，结果
- 第5段（2-3句）：整体结论、模型评价或建议

【风格要求】
- 语言精炼，全文控制在800-1200字
- 突出量化结果（具体的数值、百分比、排名等）
- 避免空泛描述如"效果较好"，要有具体数据支撑
- 不使用"我们"，使用"本文"

【关键信息】
- 问题背景：[ ]
- 问题一模型/方法/结果：[ ]
- 问题二模型/方法/结果：[ ]
- 问题三模型/方法/结果：[ ]
- 整体结论：[ ]
- 亮点数据：[ ]

请在初稿生成后，标注出你认为表述还不够具体的地方，方便我补充数据。
```

### 2. 模型段落润色提示词

**方法论：** 模型段落的润色重点是 **逻辑清晰 + 公式规范**。你自己写好草稿（哪怕语言粗糙），AI 帮你理顺逻辑链、规范符号表达。**不要把空白模型段落丢给 AI 让它从头写**——它可能编造出看起来很对但完全错误的模型。始终是你先写核心内容，AI 帮你打磨。

**提示词模板：**
```
请润色以下数学建模论文中的模型段落。要求：

【润色原则】
1. 保持我原有的数学内容不变（公式、变量定义、约束条件），只优化语言表达
2. 增强逻辑递进：先说为什么建立这个模型，再说模型是什么，最后说怎么求解
3. 规范数学符号：统一变量命名风格（如都用斜体），检查上下标
4. 修正语病和不通顺的表达
5. 控制篇幅：不要添加无实际意义的扩充

【原文】
[粘贴你的模型段落草稿]

【补充说明】
- 这个段落在论文中的位置是：[如：针对问题二的第一个模型]
- 前面的内容讲的是：[简述前文]
- 后面的内容将是：[简述后文]

修改后请指出你做了哪些主要改动，方便我核对。
```

### 3. 结果分析润色提示词

**方法论：** 结果分析的常见问题是"只有表没有分析"——放一张图表然后说"如图X所示"就结束了。好的结果分析要回答三个问题：结果是多少 → 为什么是这个结果 → 这个结果说明了什么。让 AI 帮你检查你的分析草稿是否回答了这三个问题。

**提示词模板：**
```
请帮我润色以下论文中的结果分析段落。

【我的草稿】
[粘贴你的结果分析草稿]

【对应的图表】
- 图X展示了：[描述图表内容]
- 关键数据点：[列出图中最重要的几个数值]

【润色要求】
1. 检查是否回答了三个层次：what（结果是什么）→ why（为什么会这样）→ so what（这说明了什么现实意义）
2. 如果某个层次缺失，请标注[需补充]而不是编造内容
3. 将"如图所示""从图中可以看出"等表达适当多样化
4. 增强数据与结论之间的因果逻辑，避免"因为A高所以B低"这种无依据的推断
5. 保持学术风格，不使用感叹号或过于口语化的表达
```

### 4. 中文表达优化提示词

**方法论：** 国赛论文的语言要求是 **准确 > 简洁 > 流畅**。学术中文要避免口语化（"搞定""差不多""很高的"）、模糊词（"比较""较为""相对"用得太多等于没说）、长难句（一句话超过50字读者就晕了）。AI 帮你排查这些常见问题时，要给出修改建议而非直接改。

**提示词模板：**
```
请从以下维度审查并优化这段论文文字的学术中文表达：

【原文】
[粘贴需要优化的文字]

【审查维度】
1. **口语化排查**：找出所有不够正式的用词（如"搞""弄""好多""挺"等），标注并给出替换建议
2. **模糊词排查**：找出所有"比较""较为""相对""一定的""基本上"等模糊限定词，判断是否可以换成具体数值或删除
3. **长难句拆分**：找出超过50字的句子，建议如何拆分
4. **冗余表达**：删除"进行了""做出了""进行了研究"等无信息量的动词堆砌
5. **逻辑连接**：检查段落间、句子间的逻辑连接是否清晰，是否需要补充"因此""然而""具体而言"等连接词

请对照原文逐条标注问题，给出修改后的完整版本，并简要说明主要修改了什么。
```

## ▍美赛部分（英文论文）

### 1. Summary 生成与修改提示词

**方法论：** 美赛摘要是论文的灵魂——很多评委读完摘要就决定了论文档次。美赛摘要比国赛更强调 **结果的量化呈现** 和 **模型的创新亮点**。要让 AI 先理解你的中文思路，再翻译/生成为英文摘要，避免直接中文摘要机翻——英文有自己的表达节奏。

**提示词模板：**
```
You are an expert editor for MCM/ICM (Mathematical Contest in Modeling) papers. Based on the following key information from our paper, please draft a professional Summary.

【Structure Requirements】
- Paragraph 1 (2-3 sentences): Problem background, significance, and our overall approach
- Paragraph 2 (3-4 sentences): Model for Problem 1 — what model, key methodology, main results (with NUMBERS)
- Paragraph 3 (3-4 sentences): Model for Problem 2 — how we built on/improved the first model, key results (with NUMBERS)
- Paragraph 4 (3-4 sentences): Model for Problem 3 (if applicable) — model, method, results
- Paragraph 5 (2-3 sentences): Sensitivity analysis highlights, model strengths, concluding remarks

【Style Requirements】
- Total length: approximately 350-500 words
- Use precise quantitative results (percentages, specific values, rankings)
- Use "we" (first person plural) — this is standard in MCM/ICM
- Highlight model innovation: what makes our approach different/better
- Avoid vague phrases like "good results" — be specific
- Keywords section at the end (5-8 keywords)

【Key Information】
- Background & Problem: [ ]
- Model 1 (method + results): [ ]
- Model 2 (method + results): [ ]
- Model 3 (method + results): [ ]
- Key quantitative findings: [ ]
- Sensitivity analysis highlights: [ ]
- Model strengths & innovations: [ ]

After drafting, please mark any places where MORE specific numbers or details would strengthen the summary, so I can fill them in.
```

### 2. 模型段落润色提示词（英文）

**方法论：** 英文模型段落的难点在于 **术语准确 + 数学表达规范**。中文数学术语直接翻译常常不准确（如"目标函数"是 objective function 不是 target function）。让 AI 润色时，特别要求它检查术语和数学表达是否符合国际期刊/美赛论文的惯例。

**提示词模板：**
```
Please polish the following model section from our MCM/ICM paper. This is a draft written by a non-native English speaker.

【Original Draft】
[Paste your English draft here]

【Polishing Priorities】
1. **Terminology check**: Ensure all mathematical terms are standard in English academic writing (e.g., "objective function" not "target function", "constraints" not "restrictions", "sensitivity analysis" not "sensitivity test")
2. **Logical flow**: Make the progression clear — why this model → model description → how to solve → what it produces
3. **Formula descriptions**: Ensure all inline formula explanations use consistent notation and proper English (e.g., "where X denotes..." not "where X means...")
4. **Sentence variety**: Avoid starting every sentence with "We". Vary sentence structure while keeping clarity.
5. **Conciseness**: Remove redundant phrases. Academic English values brevity.
6. **Grammar and idiomaticity**: Fix grammar errors and unnatural phrasing while preserving meaning.

【Context】
- This section appears after: [briefly describe what comes before]
- This section is followed by: [briefly describe what comes after]

After polishing, please list the major changes you made (especially terminology corrections) so I can review them.
```

### 3. 结果分析润色提示词（英文）

**方法论：** 英文结果分析的常见问题是"中式英语"——语法没问题但读起来不自然。典型特征包括：每句话以 "We" 开头、滥用 "obviously" 和 "it is clear that"、不知道怎么用英语自然地表达数据趋势（上升/下降/波动/拐点）。提示词中要列出这些典型问题让 AI 针对性检查。

**提示词模板：**
```
Please polish the following results analysis section from our MCM/ICM paper.

【Original Draft】
[Paste your English draft here]

【Corresponding Figures/Tables】
- Figure X shows: [description]
- Key data points: [list the most important numbers]

【Polishing Priorities】
1. **Beyond "We..."**: Reduce over-reliance on sentence-initial "We". Use varied constructions (passive voice where appropriate, "The results indicate...", "As shown in Figure X,...")
2. **Trend description language**: Ensure natural English for describing data trends (increase/decrease/fluctuate/plateau/peak/decline/level off — use varied and precise verbs)
3. **Remove hollow emphasis**: Replace "obviously", "it is clear that", "undoubtedly" with data-supported statements
4. **Three-level analysis**: Ensure each result answers: what (the number) → why (the reason/mechanism) → so what (the implication)
5. **Precision**: Replace vague quantifiers ("significantly", "slightly", "relatively") with actual numbers where possible
6. **Figure/table references**: Standardize as "As illustrated in Figure 3,..." or "Table 2 summarizes..."

After polishing, list the main improvements made, especially unnatural expressions that were corrected.
```

### 4. 英文表达优化提示词（综合）

**方法论：** 这个环节用于整体提升论文英文质量。除了语法和用词，还要关注 **段落衔接** 和 **全文风格一致性**。建议在论文基本成型后，把一整节或全文投给 AI 做整体语言打磨（而不是逐段处理，那样前后风格可能不一致）。

**提示词模板：**
```
Please perform a comprehensive language polish on the following section of our MCM/ICM paper. We are non-native English speakers and need the writing to reach a professional academic standard.

【Text to Polish】
[Paste the full section here]

【Overall Requirements】
1. **Grammar & Spelling**: Fix all errors
2. **Academic Tone**: Ensure formal academic register throughout — no contractions (don't → do not), no colloquialisms
3. **Terminology Consistency**: Use the same term for the same concept throughout (e.g., don't switch between "objective function" and "cost function" if they mean the same thing)
4. **Paragraph Transitions**: Ensure smooth transitions between paragraphs — the paper should read as one continuous argument, not isolated blocks
5. **Sentence Flow**: Vary sentence length and structure. Avoid monotony. Target average sentence length of 15-25 words.
6. **Math-Text Integration**: Check that every displayed equation is properly introduced before and explained after. No orphan equations.

【Prohibited — DO NOT change】
- All mathematical formulas, variable names, and numerical results
- The overall structure and paragraph order
- Technical claims and conclusions

After polishing, provide:
1. The polished text
2. A summary of the main types of corrections made (categorized by: grammar, vocabulary, sentence structure, transitions)
3. Any sentences where you were unsure about the intended meaning — flag them for my review
```
