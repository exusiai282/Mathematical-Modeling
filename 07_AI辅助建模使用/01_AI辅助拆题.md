# 01 AI 辅助拆题

拆题是建模的第一步也是最关键一步。AI 可以帮助你快速梳理题目信息、识别关键要素，但**你需要把题目原文完整提供给 AI**，否则它会胡诌。

## 1. 拆分子问题提示词

**方法论：** 一道数模题通常由 3-4 个递进的子问题组成。拆解时要关注：子问题之间的依赖关系（谁是谁的输入）、每个子问题的核心任务（是优化？评价？还是预测？）。给 AI 的提示词中，要明确要求它输出"子问题标题 + 任务类型 + 输入输出 + 依赖关系"，而不仅仅是简单拆分。

**提示词模板：**
```
你是一名数学建模竞赛辅导老师。请仔细阅读以下题目，将总任务拆分为3-5个子问题。

要求对每个子问题输出：
1. 子问题标题（一句话概括）
2. 任务类型（优化/评价/预测/分类/机理建模/其他）
3. 需要的输入数据是什么
4. 需要产出的输出是什么
5. 该子问题依赖前面哪些子问题的结果

题目如下：
[粘贴完整题目原文]
```

## 2. 提取输入输出提示词

**方法论：** 输入输出提取是建模的"骨架"。输入 = 题目给的数据 + 你可以合理收集的外部数据；输出 = 题目明确要求的结果 + 隐含需要的中间结果。很多新手忽略"隐含输出"——比如题目让"评价"，隐含输出就是排名和分数。提示词中要特别要求 AI 区分"显性"和"隐性"。

**提示词模板：**
```
请从以下题目中提取所有输入和输出要素，分为两类：

【显性输入】题目附件中直接给出的数据
【隐性输入】题目未给出但建模需要的外部数据（如公开统计数据、标准参数等）
【显性输出】题目明确要求提交的结果
【隐性输出】建模过程中需要产出的中间结果（如权重、参数、中间变量等）

对每个要素说明其格式（数值/文本/表格/图像）和大致规模。

题目如下：
[粘贴完整题目原文]
```

## 3. 分析目标与约束提示词

**方法论：** 目标和约束是建模的核心。目标函数是你要优化的东西（如成本最小、效率最高），约束是现实条件对你的限制（如预算上限、时间窗口、物理规律）。很多新手把"约束"和"假设"混淆——约束来自题目要求，假设是你为了简化自己设定的。让 AI 分开输出，有助于后续写假设部分时不搞混。

**提示词模板：**
```
请分析以下题目中的目标与约束条件：

【优化目标】
- 如果有明确的优化目标，请写出数学表达形式（如 min/max 什么）
- 如果是评价类题目没有显式目标，请说明评价的最终目的

【硬约束】（题目明确给出的限制条件，违反则结果无效）
- 请逐条列出，并尝试写出数学不等式/等式形式

【软约束】（题目暗示但未强制的要求，尽量满足）
- 请逐条列出

【不要自行添加假设】——假设是后续建模时你根据模型需要设定的，这里只需要从题目提取。

题目如下：
[粘贴完整题目原文]
```

## 4. 生成建模路线提示词

**方法论：** 建模路线 = 解决每个子问题分别用什么模型 + 模型之间的衔接方式。AI 给出的路线建议是参考，不要盲从——你需要评估每个建议模型的可行性（数据够不够？你熟不熟悉？）。给 AI 的提示词中，要求它为每个子问题推荐 2-3 个候选模型并说明优缺点，而不是只给一个"看起来最好"的方案。

**提示词模板：**
```
你现在是一名数学建模竞赛的教练。基于以下题目和我已经拆分好的子问题，请生成一份完整的建模路线图。

要求：
1. 针对每个子问题，推荐2-3个候选模型/方法
2. 对每个候选模型说明：适用条件、优点、缺点、所需数据
3. 标注各子问题之间的数据流关系（哪个模型的输出是哪个模型的输入）
4. 给出推荐的模型组合方案（整体路线），并说明理由
5. 指出整个路线中风险最大的环节（哪个步骤最容易出问题，为什么）

已拆分的子问题：
[粘贴拆分结果]

题目原文：
[粘贴完整题目原文]

如果你需要我补充任何信息才能给出更准确的建议，请直接提问。
```
