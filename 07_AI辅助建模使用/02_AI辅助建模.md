# 02 AI 辅助建模

选定模型方向后，AI 可以帮助你完善模型设计、检查漏洞、对比方案。但**AI 不真正理解数学**——它给出的公式可能看起来合理但实际有错误，必须自己验证每一条公式。

## 1. 模型选择提示词

**方法论：** 模型选择不是让 AI 替你决定用什么模型，而是让 AI 帮你做"排除法"——把你的题目特征告诉它，让它列出不适合的模型及原因，然后从剩余的选项中结合你自己的知识做选择。一定要在提示词中写明你的数据特征（样本量、数据类型、是否有缺失值等），否则 AI 的建议没有针对性。

**提示词模板：**
```
我需要为一个数学建模子问题选择合适的模型，请帮我分析。

【子问题描述】
[描述你要解决的问题]

【数据情况】
- 数据量级：约 [ ] 条记录，[ ] 个特征
- 数据类型：[数值型/类别型/文本/时间序列/空间数据]
- 数据质量：[完整/有缺失/有异常值]
- 是否有标签：[有监督/无监督]

【我初步考虑的模型方向】
[列出你想到的方向，如"想用评价方法"或"想用时间序列预测"]

请帮我：
1. 基于以上信息，推荐3-5个适合的模型，并按推荐度排序
2. 对每个模型说明：为什么适合本题、需要什么前提条件、预期的输入输出格式
3. 明确排除哪些常见但不适合的模型，并说明原因
4. 如果可能，给出模型的数学表达概述（不需要具体公式）

请用表格输出，方便对比。
```

## 2. 模型漏洞检查提示词

**方法论：** 模型漏洞检查是 AI 最有价值的用途之一。你自己设计好模型后，让 AI 扮演"评审专家"的角色来挑刺。关键技巧：**把你的模型设计完整描述给 AI**，包括假设、变量定义、公式、求解方法、数据来源。越详细，AI 找到的漏洞越有价值。最后你需要逐条评估 AI 提出的漏洞是否真的存在。

**提示词模板：**
```
你是一名数学建模竞赛的评审专家，请严格审查以下模型设计，找出所有可能的漏洞和不足之处。

【我的模型设计】
- 模型名称与类型：[ ]
- 核心假设：[逐条列出]
- 变量定义：[逐条列出，含符号和含义]
- 目标函数：[写出公式或描述]
- 约束条件：[逐条列出]
- 求解方法/算法：[描述]
- 数据来源与处理方式：[描述]
- 预期的输出结果形式：[描述]

请从以下维度逐一审查：
1. **假设合理性**：哪些假设过强？哪些假设与现实明显矛盾？是否有遗漏的关键假设？
2. **变量与指标**：是否有遗漏的重要变量？变量定义是否有歧义？指标是否可量化？
3. **公式正确性**：目标函数是否合理？约束条件是否完备？数学推导逻辑是否有问题？
4. **求解可行性**：数据是否足够支持求解？算法复杂度是否可接受？是否存在更高效的求解方法？
5. **结果可信度**：预期结果可能有哪些失真？模型在什么情况下会失效？
6. **与题目的匹配度**：模型是否完整回答了题目要求？是否有跑题或遗漏的部分？

对每个发现的问题，请标注严重程度（致命/严重/一般/建议），并给出改进方向。
```

## 3. 模型改进提示词

**方法论：** 模型改进要遵循"递进逻辑"——不是换一个更复杂的模型，而是在基础模型上逐步放松假设、增加考虑因素、优化求解方法。让 AI 帮你设计改进路线时，要明确告诉它"基础模型是什么"和"你觉得哪里不够好"。改进方案要有层次：先做最关键的改进，再考虑锦上添花。

**提示词模板：**
```
我目前的基础模型是 [模型名称]，已运行出初步结果。但我认为在以下方面还不够好：

【我对现状的不满】
1. [如：忽略了XX因素的影响]
2. [如：假设太理想化，与现实差距大]
3. [如：求解速度太慢/精度不够]

【基础模型回顾】
- 当前假设：[列出]
- 当前变量：[列出]
- 当前方法：[描述]
- 当前结果表现：[描述，如误差大小、拟合效果等]

请帮我设计模型改进方案：
1. 针对我提出的每个不足之处，给出具体的改进思路
2. 将改进方案按优先级排序（先改什么，后改什么）
3. 对每个改进方案说明：预期提升效果、实施难度、潜在风险
4. 给出一个"改进后的完整模型"描述（在基础模型上做了哪些修改）
5. 如果改进后模型变复杂，是否有简化/近似的方法保证可求解
```

## 4. 多模型对比提示词

**方法论：** 多模型对比是论文的加分项。对比的目的是说明"为什么选这个模型"，而不是摆一堆模型结果。对比要控制变量：尽可能在相同数据、相同条件下对比不同模型。让 AI 帮你设计对比框架时，要说明你打算对比哪几个模型、对比的维度是什么。

**提示词模板：**
```
我需要在论文中对以下模型进行系统的对比分析，以说明最终选择 [首选模型] 的原因。

【待对比的模型】
1. [模型A]：简要描述
2. [模型B]：简要描述
3. [模型C]：简要描述

【我打算对比的维度】
- 精度/误差
- 计算效率
- 可解释性
- 对数据的适应性
- 结果稳定性

请帮我：
1. 设计一个标准化的对比实验方案（每个模型在什么条件下运行，用什么数据，评估什么指标）
2. 给出对比结果的呈现建议（用什么图表展示）
3. 帮我撰写"模型对比分析"段落的草稿（强调为什么最终选择某个模型，而不是简单说它最好）
4. 如果某些模型表现差，建议如何客观但不贬低地描述其不足
```
