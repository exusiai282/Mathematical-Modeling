# 07 AI 辅助建模使用


> **写在前面：** AI（如 Claude、DeepSeek）是建模过程中非常强大的辅助工具，但它不能替代你的思考。AI 的定位是"加速器"——它帮你快速生成草稿、排查问题、润色表达，但**模型的逻辑正确性、结果的合理性、论文的学术判断，始终需要你来把关**。本部分的所有提示词（Prompt）都是模板，你需要根据具体题目替换 `[ ]` 中的内容。

## 使用原则

1. 将提示词中的 `[ ]` 替换为题目、数据与约束的真实信息。
2. 先让 AI 复述任务和缺失信息，再让它生成模型或代码。
3. 对公式、数据来源、代码输出和英文结论逐项人工核验。
