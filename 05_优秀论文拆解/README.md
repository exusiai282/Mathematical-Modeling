## 推荐复盘顺序

1. 首先只看 Summary，记录任务、模型、关键结果和验证方式。
2. 画出“子问题 → 模型 → 数据 → 输出”的主线。
3. 标记每次模型递进解决了基础模型的什么不足。
4. 检查核心图表分别证明了哪条结论。
5. 对照结论与摘要，判断关键数字是否前后一致。
6. 最后再记录可复用的结构与句式，不复制原文、图片或模型结论。

可使用[论文拆解模板](论文拆解模板.md)建立每篇论文的阅读笔记。图表案例的整页截图与讲解见[06 图表与结果表达](../06_图表与结果表达/README.md)。
